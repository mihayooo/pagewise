概述

智阅 PageWise（以下简称"本扩展"）是一款 Chrome 浏览器扩展（Manifest V3），帮助用户在浏览技术网页时即时向 AI 提问，并将回答自动整理成结构化知识库。

我们高度重视用户隐私。本扩展不收集、不存储、不传输任何用户数据至开发者控制的服务器。

1. 数据收集

本扩展不收集任何用户数据。

我们不会收集、存储或传输以下信息：

  • 个人信息（姓名、邮箱、地址等）
  • 浏览历史记录
  • Cookie 或追踪标识符
  • 设备信息或地理位置数据

本扩展不集成任何广告 SDK、分析工具或第三方追踪器。

2. 数据存储

所有数据均存储在用户本地浏览器中，使用浏览器原生存储 API。

存储类型用途持久性
chrome.storage.sync用户设置、API 配置 Profile跟随 Google 账号同步
chrome.storage.local高亮标注、使用统计、自定义模板、快捷键配置、反馈数据、性能指标本地持久化
chrome.storage.session当前对话上下文、临时状态关闭浏览器后自动清除
IndexedDB知识库条目、对话历史、Wiki 页面、自定义技能、书签索引、学习路径本地持久化

重要说明：

  • API 密钥存储在 chrome.storage.sync 中，由 Chrome 浏览器加密保护
  • 所有知识库数据存储在浏览器本地 IndexedDB 中
  • 任何数据都不会上传到本扩展开发者的服务器

3. v3.3.0 — v3.4.0 新增数据处理

v3.3.0 至 v3.4.0 版本新增了以下本地数据处理功能。所有新增功能均仅在用户浏览器内本地运行，不涉及任何网络传输。

3.1 运行时性能监控（v3.4.0 — R277）

新建 lib/performance-monitor.js 模块，用于追踪扩展内部运行时性能指标：

监控指标说明存储方式
SidePanel 首屏渲染时间侧边栏打开到内容展示的耗时内存 FIFO 采样（最大 1000 条）
知识库查询延迟IndexedDB 全文搜索的响应时间内存 FIFO 采样
AI 响应时间从发送请求到收到完整回答的耗时内存 FIFO 采样
IndexedDB 事务耗时存储读写操作的性能内存 FIFO 采样
  • 采集范围：仅采集时间戳（毫秒级），不采集页面内容、用户输入或 AI 回答
  • 存储位置：仅存储在内存中（JavaScript 变量），不写入磁盘或网络
  • 数据上限：FIFO 采样淘汰策略，最多保留 1000 条采样点
  • 网络传输：无。性能数据仅用于本地诊断，不发送至任何服务器
  • 用户控制：关闭扩展后数据自动清除

3.2 用户反馈收集（v3.3.0 — R212）

lib/feedback-collector.js 模块在扩展安装满 7 天后提供 NPS（净推荐值）评分反馈界面：

数据项说明存储方式
NPS 评分（0-10）用户对扩展的推荐意愿评分chrome.storage.local
文字反馈（可选）用户自由填写的改进建议chrome.storage.local
反馈时间戳反馈提交时间chrome.storage.local
  • 触发条件：安装满 7 天后弹出一次提示，用户可选择忽略
  • 网络传输：无。反馈数据仅存储在本地，不发送至任何服务器
  • 用户控制：用户可在设置页查看和删除反馈数据；卸载扩展即清除所有数据

3.3 使用统计遥测（v3.3.0 — R212）

lib/telemetry.js 模块记录功能使用次数统计：

  • 采集内容：功能名称 + 使用次数（如 ask_ai: 42、bookmark_op: 15），不含具体内容
  • 存储位置：chrome.storage.local
  • 网络传输：无。统计数据仅用于本地展示使用习惯概览
  • 用户控制：可在设置中关闭遥测（telemetryEnabled: false）

3.4 跨浏览器兼容层（v3.4.0 — R278）

lib/browser-compat.js 和 lib/storage-adapter.js 提供浏览器 API 统一抽象层：

  • 功能：统一 chrome.* 和 browser.* API 命名空间，Promise 化回调 API
  • 数据处理：纯适配层，不采集、存储或传输任何用户数据
  • 隐私影响：无。仅为 API 调用提供统一接口，不改变数据流

4. 数据传输

本扩展仅在用户主动操作时，向用户自行配置的 AI API 端点发送请求。

4.1 AI API 请求

当用户主动提问时，本扩展会将页面内容和用户问题发送到用户在设置中配置的 AI API 地址：

服务域名说明
Anthropic Claudeapi.anthropic.comClaude 模型 API
OpenAIapi.openai.comGPT 模型 API
DeepSeekapi.deepseek.comDeepSeek 模型 API
本地 AI 服务localhost / 127.0.0.1Ollama 等本地模型
自定义端点用户自行配置任意 OpenAI 兼容 API

4.2 数据传输控制

  • 所有 API 请求均由用户主动触发（点击发送按钮或快捷键）
  • API 密钥和端点由用户自行配置和管理
  • 用户可随时在设置中修改或删除 API 配置
  • 本扩展不会将数据发送到扩展开发者控制的任何服务器
  • v3.4.0 性能监控、反馈收集、使用统计均不涉及网络传输

6. 第三方服务

本扩展依赖以下第三方服务，均由用户自行选择和配置：

  • AI API 服务：用户自行选择的 AI 模型提供商，数据传输取决于用户选择的服务提供商的隐私政策
  • 浏览器内置 API：Chrome 浏览器提供的存储、标签页、书签等原生 API，遵循 Google Chrome 隐私政策

无第三方 SDK：本扩展不集成广告网络、分析/统计工具、用户行为追踪器、社交媒体 SDK 或错误追踪服务。

7. Content Security Policy

本扩展声明了严格的 Content Security Policy：

script-src 'self'; object-src 'self';
  • 仅允许加载扩展自身的脚本
  • 禁止内联脚本执行
  • 禁止 eval() 动态代码执行
  • 禁止加载外部脚本资源

8. 数据删除

用户可以随时通过以下方式删除所有本地数据：

  1. 扩展内删除：在设置页面清除知识库和对话历史
  2. 批量清除：使用「清除所有数据」按钮删除所有扩展数据
  3. 浏览器设置：在 Chrome 设置中清除扩展数据
  4. 卸载扩展：卸载后所有本地存储数据将被清除（包括性能监控、反馈、遥测数据）

9. 儿童隐私

本扩展不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

10. 隐私政策变更

如本隐私政策发生重大变更，我们将在：

  • Chrome Web Store 更新说明中注明
  • 本隐私政策页面更新"最后更新日期"
