## Detailed Description

### 🧠 PageWise — Your AI Reading Assistant

PageWise is a powerful Chrome extension that makes AI your reading companion. Whether you're reading technical docs, research papers, or blog posts — select any text and ask AI for instant, accurate answers.

---

### ✨ Core Features

**🤖 AI-Powered Q&A**
- Select text on any webpage and ask AI questions instantly
- Supports Claude, GPT-4o, DeepSeek and other leading AI models
- Streaming output with rich Markdown rendering
- Code highlighting, tables, and math formula support
- Multi-turn conversations with automatic context

**📚 Smart Knowledge Base**
- Q&A automatically archived to local knowledge base (IndexedDB)
- Full-text search + semantic search for instant retrieval
- Tag classification and knowledge graph visualization
- Export to Markdown/JSON formats

**🔖 Bookmark Knowledge Graph**
- Auto-collect Chrome bookmarks and build knowledge graphs
- Force-directed graph visualization to discover knowledge connections
- AI-powered recommendations: pattern analysis, gap detection
- Bookmark clustering, tag management, duplicate detection
- Link health checks and learning path planning

**⚡ Intelligent Skill System**
- 7 built-in skills: translate, summarize, explain, code review, and more
- Custom skill editor for personalized AI workflows
- Skill marketplace: community sharing and import/export

**♿ Accessibility Compliant (WCAG 2.1 AA)**
- Full keyboard navigation support (Arrow/Tab/Enter/Escape)
- Screen reader compatible (ARIA roles and Live Region)
- High contrast mode support
- Focus management with focus traps

**🌐 Cross-Browser Compatible**
- Unified API compatibility layer for Chrome/Firefox/Edge
- Storage adapter layer for cross-platform data consistency

---

### 🔒 Privacy First

- ✅ **All data stored locally** in your browser — never uploaded to any server
- ✅ AI requests only go to **your configured API endpoint**
- ✅ No ads, analytics tools, or trackers integrated
- ✅ API keys encrypted by Chrome storage
- ✅ Strict CSP policy — no inline scripts or eval

---

### 🚀 Quick Start

1. After installation, click the extension icon or press `Ctrl+Shift+Y` to open the sidebar
2. Configure your AI API key in Settings
3. While browsing, select text and ask AI questions
4. All Q&A is auto-archived in the knowledge base for future reference

### ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+Y` | Open sidebar |
| `Ctrl+Shift+S` | Summarize current page |
| `Ctrl+Shift+X` | Toggle sidebar |
| `Ctrl+K` | Open Chat mode |
