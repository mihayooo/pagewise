## 详细描述

### 🧠 智阅 PageWise — 你的 AI 网页阅读助手

智阅 PageWise 是一款功能强大的 Chrome 浏览器扩展，让 AI 成为你的阅读伙伴。无论是技术文档、学术论文还是博客文章，选中文字即可向 AI 提问，获得即时、精准的回答。

---

### ✨ 核心功能

**🤖 AI 智能问答**
- 选中网页文字，一键向 AI 提问
- 支持 Claude、GPT-4o、DeepSeek 等主流 AI 模型
- 流式输出，Markdown 富文本渲染
- 支持代码高亮、表格、数学公式
- 多轮对话，上下文自动关联

**📚 智能知识库**
- 问答自动归档到本地知识库（IndexedDB）
- 全文搜索 + 语义搜索，快速找到历史问答
- 标签分类、知识图谱可视化
- Markdown/JSON 多格式导出

**🔖 书签知识图谱**
- 自动采集 Chrome 书签，构建知识图谱
- 力导向图可视化，发现知识关联
- AI 智能推荐：收藏模式分析、知识盲区检测
- 书签聚类、标签管理、重复检测
- 链接健康检查、学习路径规划

**⚡ 智能技能系统**
- 7 个内置技能：翻译、总结、解释、代码审查等
- 自定义技能编辑器，创建个性化 AI 工作流
- 技能市场：社区分享与导入导出

**♿ 无障碍合规 (WCAG 2.1 AA)**
- 完整键盘导航支持（Arrow/Tab/Enter/Escape）
- 屏幕阅读器兼容（ARIA 角色与 Live Region）
- 高对比度模式支持
- 焦点管理与焦点陷阱

**🌐 跨浏览器兼容**
- 统一 API 兼容层，支持 Chrome/Firefox/Edge
- 存储适配层，跨平台数据一致性

---

### 🔒 隐私优先

- ✅ **所有数据存储在本地浏览器**，不上传至任何服务器
- ✅ AI 请求仅发送到**你自行配置的 API 端点**
- ✅ 不集成任何广告 SDK、分析工具或追踪器
- ✅ API 密钥由 Chrome 加密存储
- ✅ 严格 CSP 策略，禁止内联脚本和 eval

---

### 🚀 快速开始

1. 安装扩展后，点击扩展图标或按 `Ctrl+Shift+Y` 打开侧边栏
2. 在设置中配置你的 AI API 密钥
3. 浏览网页时，选中文字即可向 AI 提问
4. 所有问答自动归档到知识库，随时检索回顾

### ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+Y` | 打开侧边栏 |
| `Ctrl+Shift+S` | 总结当前页面 |
| `Ctrl+Shift+X` | 打开/关闭侧边栏 |
| `Ctrl+K` | 打开 Chat 模式 |
