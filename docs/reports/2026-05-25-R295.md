## 4. 设计决策

| ID | 决策 | 原因 |
|----|------|------|
| D1 | preflight 用 bash | Node.js 不可用时仍能检查 |
| D2 | 语法检查采样 20 个 | 全量 215 个太慢，采样足够发现系统性问题 |
| D3 | preflight 在 test:ci 之前 | 是 test:ci 的前置门禁 |
| D4 | eslint --version 验证 | 确保 eslint 可执行 |
| D5 | 10 个 lib 模块跨功能域 | utils/storage/graph/ai/knowledge/compat |

## 5. 防断裂机制

- preflight 失败 → 明确标记"基础设施错误"而非"测试失败"
- CI workflow 顺序：install → preflight → test:ci
- test-infra-health.js 持续验证基础设施健康状态
- 未来 Node 版本/依赖/配置变更触发 preflight 红灯
